# Cách dùng trên Overleaf

Upload các file trong thư mục này lên Overleaf:

- `main.tex`
- `references.bib`

Template lớp dùng `IEEEtran`, đúng với file hướng dẫn trong `hướng_dẫn_latex_lớp_CD_TDT.zip`. Overleaf thường có sẵn `IEEEtran`. Nếu project Overleaf báo thiếu class, upload thêm `IEEEtran.cls` từ file zip hướng dẫn.

Khuyến nghị build:

- Compiler: pdfLaTeX.
- Bibliography: BibTeX.
- Nếu lỗi tiếng Việt với package `vietnam`, đổi compiler sang pdfLaTeX trong Overleaf và đảm bảo file lưu UTF-8.

Giới hạn trang:

- Bản hiện tại được viết theo format IEEE hai cột và hướng tới tối đa 10 trang.
- Nếu vượt trang, cắt bớt phần Related Work hoặc bảng hyperparameter trước, không cắt Abstract/Result/Limitations.
